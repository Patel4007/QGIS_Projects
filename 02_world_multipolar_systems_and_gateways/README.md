# World Multipolar Systems & Gateways

World project combining countries, economic hubs, transition leaders, and major intercontinental gateway corridors.

## Included Files

- Project: `02_world_multipolar_systems_and_gateways.qgz`
- Data: `data/02_world_multipolar_systems_and_gateways.gpkg`
- Large-format PDF: `exports/02_world_multipolar_systems_and_gateways_layout.pdf`

## Notes

- This project is the suite-wide global overview with a saved world opening extent.
- Gateway spheres and corridor lines are presentation-focused analytical layers for global systems mapping.
- Seven bookmarks move between Atlantic, Eurasian, Indo-Pacific, Americas, Europe-Africa, and East Asia frames without losing the global context.

## Data Basis

- Real country polygons from the offline Natural Earth low-resolution dataset bundled locally with the QGIS Python environment.
- Several indicator and corridor layers are analytical derivatives created for map design and comparison, not official observed datasets.
