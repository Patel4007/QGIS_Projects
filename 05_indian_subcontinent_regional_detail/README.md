# Indian Subcontinent Regional Detail & Mobility Network

Detailed Indian subcontinent project built for zooming into mobility corridors, dense metro belts, and regional service clusters.

## Included Files

- Project: `05_indian_subcontinent_regional_detail.qgz`
- Data: `data/05_indian_subcontinent_regional_detail.gpkg`
- Large-format PDF: `exports/05_indian_subcontinent_regional_detail_layout.pdf`

## Notes

- This is the most zoomable project in the suite, with a finer analytical grid than the continental maps.
- Mobility zones are derived from metro clustering, corridor reach, and country-level density and pressure signals.
- Seven bookmarks jump into Delhi NCR, Mumbai Ahmedabad, Southern Tech Belt, the Dhaka delta, the northwest spine, and the Himalayan arc.

## Data Basis

- Real country polygons from the offline Natural Earth low-resolution dataset bundled locally with the QGIS Python environment.
- Several indicator and corridor layers are analytical derivatives created for map design and comparison, not official observed datasets.
