# Africa Gateway Trade & Resilience Systems

Advanced Africa project combining resilience-led country mapping, continental corridors, gateway hubs, and clipped trade-interface zones.

## Included Files

- Project: `06_africa_gateway_trade_and_resilience.qgz`
- Data: `data/06_africa_gateway_trade_and_resilience.gpkg`
- Large-format PDF: `exports/06_africa_gateway_trade_and_resilience_layout.pdf`

## Notes

- This project balances continent-wide structure with subregional gateway detail.
- Analytical zones combine gateway clustering, corridor reach, resilience, and transition signals.
- Bookmarks focus on the Gulf of Guinea, Nile-Red Sea, East Africa, and Southern Africa industrial systems.

## Data Basis

- Real country polygons from the offline Natural Earth low-resolution dataset bundled locally with the QGIS Python environment.
- Several indicator and corridor layers are analytical derivatives created for map design and comparison, not official observed datasets.
